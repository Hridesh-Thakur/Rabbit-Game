# Rabbit Game 🐇

A fun and interactive browser-based rabbit game built using HTML, CSS, and JavaScript.  
Jump into the game, control the rabbit, avoid obstacles, and enjoy smooth gameplay in your browser.

## Project Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/Hridesh-Thakur/Rabbit-Game.git
   ```

2. Open the project folder:
   ```bash
   cd Rabbit-Game
   ```

3. Run the project by opening the `index.html` file in your browser.
